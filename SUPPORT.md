# Support

This is an independent community project maintained in spare time. It is not affiliated with or
supported by Broadcom.

| You need | Go to |
| --- | --- |
| How to install, configure or troubleshoot | [Documentation](docs/) and the [project page](https://djonko.dev/projects/template-tool) |
| A bug or unexpected behaviour | [Open a bug report](../../issues/new?template=bug_report.yml) |
| To tell us it works (or not) on your version | [Compatibility report](../../issues/new?template=compatibility_report.yml) |
| A security problem | [Report privately](../../security/advisories/new) |
| Help with VCF Operations itself | Broadcom support |

Responses are best effort. Issues with clear, redacted output get answered first.
