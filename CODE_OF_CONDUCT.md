# Code of conduct

This project is a place for practitioners to share what works. Keep it that way.

- Be respectful and assume good intent. Disagree about the technical point, not the person.
- Be helpful to people at every level of experience.
- No harassment, insults, discriminatory language or personal attacks, in any project space.
- Do not post anyone's private information, including other people's environment details.

The maintainer may edit or remove comments, close issues, and block accounts that break these rules.
To report a problem privately, use the contact details on [djonko.dev](https://djonko.dev).

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
